# えぬチャリ

えぬキャラが自転車で崖を飛び越えながらひたすら走る、スマホ専用エンドレスランナー。

## 遊び方

- **タップ**（またはクリック）でジャンプ
- **2段ジャンプあり**（タップ2回で高くジャンプ）
- 崖（地面の切れ目）に落ちるとゲームオーバー
- スコア = 走った距離（m）
- ゲームオーバー後に「シェア」ボタンでXに結果投稿

## 地形の仕組み

地面は3段階の高さが組み合わさって生成されます。

| 高さ | 特徴 |
|------|------|
| LOW（低地） | スタート地点の高さ |
| MID（中段） | 1段ジャンプで届く |
| HIGH（高台） | 2段ジャンプが必要なことも |

距離が伸びるほど崖が増え・広くなり、高低差も大きくなります。

また「直接崖落とし」も存在し、隙間なく地面が低くなる段差に注意が必要です。

## シェア機能

シェアボタンを押すと、以下が自動で含まれます：

- ハッシュタグ：`#えぬチャリ`
- メンション：`@enu_dev`
- 走った距離・ゲームURL

## 機能

- タップだけで遊べる極シンプル設計
- 距離に比例してスピードアップ・崖が増加
- 背景が時間帯で変化（夜明け前 → 朝焼け → 昼 → 夕方 → 夜）
- ベストスコア・累計プレイ回数をローカル保存
- Web Share API対応（対応ブラウザでネイティブシェア）

## 技術スタック

- HTML / CSS / JavaScript（バニラ・ライブラリゼロ）
- Canvas API（描画）
- localStorage（スコア保存）
- Web Share API（シェア）

> ビルドツールなし。HTMLファイルをブラウザで開けば即動きます。

## 推奨環境

- **スマホ推奨**（縦持ち）
- iOS Safari / Android Chrome で動作確認済み
- PCでも動作（スペースキー / クリックでジャンプ）
